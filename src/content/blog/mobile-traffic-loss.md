# چرا ۸۰٪ کاربران موبایل سایتت رو ترک می‌کنن؟

بیش از **۷۰٪ ایرانی‌ها سایت‌ها رو روی موبایل می‌بینن**. اگه سایتت روی موبایل درست کار نکنه، ۸۰٪ این کاربران سایتت رو ترک می‌کنن.

## چطور بفهمی سایتت مشکل داره؟

**تست سریع:**

۱. گوشیت رو بردار
۲. سایتت رو باز کن
۳. چک کن:
- [ ] بدون زوم، همه‌ی متن‌ها خوانا هستن؟
- [ ] دکمه‌ها به‌اندازه‌ی کافی بزرگ هستن؟
- [ ] اسکرول افقی نداری؟
- [ ] فرم‌ها راحت پر می‌شن؟
- [ ] سرعت لود زیر ۳ ثانیه‌ست؟

## ۷ مشکل اصلی و راه‌حل

### ۱. متن‌ها ریز هستن

فونت‌ها باید حداقل **۱۶px** باشن روی موبایل.

### ۲. دکمه‌ها خیلی کوچیکن

حداقل اندازه: **۴۸px × ۴۸px** (استاندارد Apple و Google).

### ۳. اسکرول افقی

همه‌ی عکس‌ها باید `max-width: 100%` باشن.

### ۴. پاپ‌آپ‌های آزاردهنده

توی موبایل، پاپ‌آپ‌ها رو کوچیک‌تر کن یا حذفشون کن.

### ۵. فرم‌ها سخت پر می‌شن

هر فیلد یه **input type** درست داشته باشه (tel، email).

### ۶. سرعت پایین

تصاویر بهینه (WebP)، حداقل JavaScript، هاست سریع.

### ۷. منوی موبایل بی‌کیفیت

منوی همبرگری استاندارد + **لمسی** (نه هاور).

## چطور تست کنی؟

**Chrome DevTools:** `F12` → `Ctrl+Shift+M` → iPhone 12 Pro.

**بهترین تست:** با گوشی واقعی.

## چک‌لیست ۱۰ موردی

- [ ] فونت‌ها حداقل ۱۶px
- [ ] دکمه‌ها حداقل ۴۸px
- [ ] بدون اسکرول افقی
- [ ] سرعت لود زیر ۳ ثانیه
- [ ] فرم‌ها با input type درست
- [ ] عکس‌ها ریسپانسیو
- [ ] منوی موبایل لمسی
- [ ] پاپ‌آپ‌ها قابل بستن راحت
- [ ] متن‌ها بدون زوم خوانا
- [ ] تست شده روی حداقل ۲ گوشی
